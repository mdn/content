The **`permissions`** module contains commands for managing browser permissions.
This module is a WebDriver BiDi extension defined by the [Permissions specification](https://w3c.github.io/permissions/#automated-testing-with-webdriver-bidi).

## Commands

- [`permissions.setPermission`](/en-US/docs/Web/WebDriver/Reference/BiDi/Modules/permissions/setPermission)

## Events

The `permissions` module has no associated events.
