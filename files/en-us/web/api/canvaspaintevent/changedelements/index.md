{{APIRef("HTML-in-Canvas API")}}

The **`changedElements`** read-only property of the {{domxref("CanvasPaintEvent")}} interface is an array of references to the [`drawable`](/en-US/docs/Web/HTML/Reference/Global_attributes/drawable) elements that were repainted when the {{domxref("HTMLCanvasElement.paint_event", "paint")}} event fired.

## Value

An array of element references.
