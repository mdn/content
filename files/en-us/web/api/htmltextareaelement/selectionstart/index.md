{{APIRef("HTML DOM")}}

The **`selectionStart`** property of the {{domxref("HTMLTextAreaElement")}} interface specifies the start position of the current text selection in a {{HTMLElement("textarea")}} element.

For general information about this property, see {{domxref("HTMLInputElement.selectionStart")}}.

## Value

A non-negative number representing the zero-based index of the first selected character, or the caret position if no text is selected.
