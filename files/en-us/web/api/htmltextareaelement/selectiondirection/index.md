{{APIRef("HTML DOM")}}

The **`selectionDirection`** property of the {{domxref("HTMLTextAreaElement")}} interface is a string that indicates the direction in which the user is selecting the text.

For general information about this property, see {{domxref("HTMLInputElement.selectionDirection")}}.

## Value

A string: `"forward"`, `"backward"`, or `"none"`.
