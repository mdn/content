{{APIRef("File and Directory Entries API")}}{{Non-standard_Header}}

The read-only **`name`** property of the {{domxref("FileSystemSync")}} interface represents the name of the file system. The name must be unique across the list of exposed file systems.

## Value

A string that represents the name of the file system.

## Specifications

This feature is not part of any specification anymore. It is no longer on track to become a standard.
