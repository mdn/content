{{APIRef("File and Directory Entries API")}}{{Non-standard_Header}}

The read-only **`root`** property of the {{domxref("FileSystemSync")}} interface represents the root directory of the file system.

## Value

A {{domxref("DirectoryEntry")}} that is the root directory of the file system.

## Specifications

This feature is not part of any specification anymore. It is no longer on track to become a standard.
