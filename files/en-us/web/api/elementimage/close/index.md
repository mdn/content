{{APIRef("Canvas API")}}

The **`close()`** method of the {{domxref("ElementImage")}} interface removes an `ElementImage`, freeing up the memory used to store it.

## Syntax

```js-nolint
close()
```

### Parameters

None.

### Return value

None ({{jsxref("undefined")}}).

See the main {{domxref("ElementImage")}} page for an example.
