The **`xlink:role`** attribute specifies a URI reference that identifies the role or meaning of the target resource in the context of XLink.

> [!NOTE]
> SVG 2 removed the need for the `xlink` namespace. The `xlink:role` attribute is obsolete and should not be used in modern SVG content.
