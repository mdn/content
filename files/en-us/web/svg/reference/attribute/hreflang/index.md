The **`hreflang`** attribute indicates the human language of the resource linked by an SVG {{SVGElement("a")}} element. You can use this attribute with the following SVG elements:

- {{SVGElement("a")}}

## Example

```html
<svg viewBox="0 0 150 20" xmlns="http://www.w3.org/2000/svg">
  <a href="https://example.com" hreflang="en">
    <text x="5" y="15">Website</text>
  </a>
</svg>
```
