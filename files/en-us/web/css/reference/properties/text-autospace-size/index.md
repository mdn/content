The **`text-autospace-size`** [CSS](/en-US/docs/Web/CSS) property allows you to specify th size of the space between Chinese/Japanese/Korean (CJK) and non-CJK characters when using the {{cssxref("text-autospace")}} CSS property.

## Syntax

```css
text-autospace-size: 1.1;
text-autospace-size: 0.2;

/* Global values */
text-autospace: inherit;
text-autospace: initial;
text-autospace: revert;
text-autospace: revert-layer;
text-autospace: unset;
```

## Values

- {{cssxref("&lt;number&gt;")}}
  - : Autospace size. The default value is `0.125` of the font-size of the CJK characters.
