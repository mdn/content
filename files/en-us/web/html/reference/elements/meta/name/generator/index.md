The **`generator`** value for the [`name`](/en-US/docs/Web/HTML/Reference/Elements/meta/name) attribute of the {{htmlelement("meta")}} element identifies software that generated the document.
If specified, the software name is provided using the [`content`](/en-US/docs/Web/HTML/Reference/Elements/meta#content) attribute as a free-form string.

For example, a static site generator called "ExamplePress" could identify itself in the generated document:

```html
<meta name="generator" content="ExamplePress 4.2" />
```

The `generator` value should not be used for documents whose markup was written manually rather than generated by software.

## Usage notes

A `<meta name="generator">` element has the following additional attributes:

- [`content`](/en-US/docs/Web/HTML/Reference/Elements/meta#content)
  - : A free-form string that identifies one of the software packages used to generate the document.

## Examples

### Identifying the document generator

The following example indicates that the document was generated using WordPress 6.8:

```html
<meta name="generator" content="WordPress 6.8" />
```
